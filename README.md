# DarkKnight

A dark-themed Java project built to explore object-oriented programming, character design, and simple game-like behavior.

## Overview

DarkKnight is a beginner-friendly Java application inspired by a mysterious warrior character. The project focuses on demonstrating core OOP concepts such as classes, objects, attributes, methods, and interaction between entities in a structured and readable way.

## Features

- Java-based character modeling
- Object-oriented design
- Clean and simple code structure
- Dark, cinematic theme
- Easy to understand for learners

## Tech Stack

- Java
- JDK
- Command-line execution

## Getting Started

### Prerequisites

- Java Development Kit (JDK) installed
- A terminal or Java IDE

### Run the Project

```bash
javac DarkKnight.java
java DarkKnight
```
